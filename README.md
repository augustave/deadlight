# DEADLIGHT

This folder is now a small React/Vite viewer for the DEADLIGHT specification artifacts.

## Structure

- `src/artifacts/v2/` holds the April 2, 2026 canonical rulebook.
- `src/artifacts/v1/` holds the March 28, 2026 legacy artifacts.
- `docs/content-audit.md` summarizes the important drift between v1 and v2.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
