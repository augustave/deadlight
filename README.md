# DEADLIGHT

React/Vite app for browsing the DEADLIGHT rulebook and supporting artifact set.

## Structure

- `src/artifacts/v2/` holds the April 2, 2026 canonical rulebook.
- `src/artifacts/v1/` holds the March 28, 2026 legacy artifacts.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
